
# Backend Bun + Express

API backend desarrollada con Bun, Express y TypeScript.

## Requisitos

- Bun
- Git

## Instalación

```bash
bun install
```

## Variables de entorno

Crear un archivo `.env` a partir de `.env.example`.

## Desarrollo

```bash
bun run index.ts
```

## Verificación

GET `/api/health`

Devuelve el estado del servidor.
